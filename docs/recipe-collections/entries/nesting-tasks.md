# Meals to impress

Source path: `/discover/collection/nesting-tasks`

Meals to impress All of these have multiple components. Practice cooking efficiently by tackling a few different items at once. Start with the pieces that take the longest to cook through (like rice), then use that downtime to tackle another part of the recipe. The instructions will walk you through it!
